# JGB37-520 编码器、测速与 PID

本项目使用两台 `JGB37-520` 有刷直流减速电机，额定电压 12 V，减速比
6.3:1，输出轴标称转速 1580 rpm。

项目文件：

- `Core/Src/jgb37_520_encoder.c`
- `Core/Inc/jgb37_520_encoder.h`
- `Core/Src/jgb37_520_pid.c`
- `Core/Inc/jgb37_520_pid.h`

参数与实现思路参考了 Apache-2.0 项目
<https://github.com/chenzhaoqiJM/stm32-JGB37-520-control>。本项目针对现有
STM32 HAL、定时器和板级映射重新实现，没有复制上游源代码。许可证见
[`JGB37_520_LICENSE.txt`](JGB37_520_LICENSE.txt)。

## 六线接口

| 颜色 | 信号 | 接法 |
| :--- | :--- | :--- |
| 红 | 电机电源正 | TB6612 电机输出端之一 |
| 白 | 电机电源负 | TB6612 另一电机输出端 |
| 蓝 | 编码器电源正 | 3.3 V |
| 黑 | 编码器电源负 | GND，与 STM32、TB6612 共地 |
| 黄 | 编码器 A 相 / C1 | 对应电机的编码器 CH1 |
| 绿 | 编码器 B 相 / C2 | 对应电机的编码器 CH2 |

编码器允许 3.3 V 或 5 V 供电，输出为推挽方波。本项目统一使用 3.3 V，避免
5 V 推挽信号直接接入 STM32。红白线互换只改变电机旋转方向；黄绿线互换只改变
编码器计数方向。软件也可以通过方向取反配置校正，但接线和软件只能选择一个位置
进行取反，避免重复反相。

本板映射：

- 电机 A：PWM 为 PA11/TIM1_CH4，方向为 PB12/PB13，编码器为
  PB6/PB7 的 TIM4_CH1/CH2。
- 电机 B：PWM 为 PA8/TIM1_CH1，方向为 PB1/PB0，编码器为全重映射后的
  PA15/PB3（TIM2_CH1/CH2）。

TIM2 和 TIM4 均使用 Encoder Mode TI1 and TI2。编码器计数采用 16 位差分
轮询，不开启 CC1/CC2 逐边沿中断。

## 编码器参数与转速

编码器磁环为 22 极（11 对极），电机轴每圈每相输出 11 个完整脉冲。STM32
TI12 模式对 A、B 两相的上升沿和下降沿计数，形成四倍频：

```text
电机轴每圈计数 = 11 PPR * 4 = 44 counts
输出轴每圈计数 = 44 * 6.3 = 277.2 counts
RPM = delta_counts * 60 / (counts_per_output_rev * sample_period_s)
```

默认值集中定义在 `jgb37_520_encoder.h`：

```c
JGB37_520_ENCODER_BASE_PPR          11.0f
JGB37_520_ENCODER_QUADRATURE_FACTOR  4.0f
JGB37_520_GEAR_RATIO                 6.3f
JGB37_520_COUNTS_PER_OUTPUT_REV    277.2f
JGB37_520_NOMINAL_OUTPUT_RPM      1580.0f
```

标称转速下预计约为 7300 counts/s；10 ms 采样周期内约为 73 counts。实际计数
是整数，因此单周期 RPM 会有量化波动，可通过固定周期采样和适度滤波处理。1580 rpm
只用于结果合理性检查，不是软件限速值。

主要接口：

- `jgb37_520_encoder_init()`：使用 277.2 counts/rev 初始化。
- `jgb37_520_encoder_init_calibrated()`：使用实测的每圈计数初始化。
- `jgb37_520_encoder_delta_u16()`：计算可跨越 16 位回绕点的有符号增量。
- `jgb37_520_encoder_update()`：累计计数并计算输出轴有符号 RPM。
- `jgb37_520_encoder_reset()`：清空采样计数、累计计数和 RPM。

## 每圈计数标定

1. 架空车轮并保持 PWM 为 0，确认编码器由 3.3 V 供电且 MCU 与驱动共地。
2. 清零定时器和软件累计计数。
3. 在输出轴和机壳上做对齐标记，缓慢转动输出轴 10 圈，避免单圈取整误差。
4. 用累计计数绝对值除以 10，结果应接近 277.2。
5. 将实测值传给 `jgb37_520_encoder_init_calibrated()`；若符号与定义方向相反，
   交换黄绿线或在软件中反相一次。

## PID

`jgb37_520_pid` 是不访问硬件的通用浮点 PID。它提供输出限幅、积分限幅、
首次更新微分抑制和复位，并拒绝空指针、非法限幅及非正采样周期。主要接口为：

- `jgb37_520_pid_init()`
- `jgb37_520_pid_update()`
- `jgb37_520_pid_reset()`

编码器与 PID 模块已加入构建，但 `main.c` 尚未创建对应对象或启用闭环。
完成编码器方向和每圈计数标定后，再根据实车负载逐步整定 PID。

当前 `main.c` 另有独立的开环直行测试：A1 为左轮、B1 为右轮，上电后两路
均使用 10% PWM。实车确认的前进方向为 A1 的 `AIN1=1/AIN2=0`、B1 的
`BIN1=1/BIN2=0`。如果整车后退，应同时反转两组方向；如果原地转向，只反转
方向错误的那一组。该测试不启用编码器闭环。

## 上板安全

1. 首次测试必须架空车轮，并从低占空比开始确认两台电机方向。
2. 确认 TB6612 的 STBY 已由硬件可靠上拉后再启动 PWM。
3. TB6612 的电机电压范围可以覆盖 12 V，但必须另行核对 JGB37-520 的堵转
   电流、驱动板散热和电源瞬态；型号和额定电压本身不能证明电流能力足够。
4. 不要在电机通电时插拔六线编码器接口。

TIM2 用于电机 B 编码器后不能再作为超声波自由运行计数器。HC-SR04 当前使用
PB10 双边沿 EXTI，并读取 1 MHz TIM3 作为时间戳，此资源分配保持不变。
