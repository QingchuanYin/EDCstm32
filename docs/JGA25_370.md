# JGA25-370 编码器与 PID

项目文件：

- `Core/Src/jga25_370_encoder.c`
- `Core/Inc/jga25_370_encoder.h`
- `Core/Src/jga25_370_pid.c`
- `Core/Inc/jga25_370_pid.h`

资料来源：<https://github.com/Dimicod/stm32-pid-controller>

## 编码器

`jga25_370_encoder` 负责保存采样周期内的编码器计数，并根据有效每圈脉冲数
计算输出轴转速：

```text
RPM = (本周期脉冲数 / 有效每圈脉冲数) * (60 / 采样周期秒数)
```

有效每圈脉冲数应包含编码器物理线数、正交解码倍频和减速箱速比。例如资料中
采用 11 线编码器、4 倍频和约 32:1 减速比，有效值为 `11 * 4 * 32 = 1408`。

主要接口：

- `encoder_init()`：设置有效每圈脉冲数。
- `encoder_update()`：写入当前采样周期的计数值。
- `encoder_compute_rpm()`：计算转速。
- `encoder_reset()`：清空计数与转速。

## PID

`jga25_370_pid` 是带输出限幅和积分限幅的通用 PID 算法，主要接口为
`pid_init()`、`pid_compute()` 和 `pid_reset()`。

该资料原工程使用 L298N，本项目使用 TB6612，因此没有复制其中的 L298N
`motor.c/.h`。本板可考虑使用 PB6/PB7 的 TIM4_CH1/TIM4_CH2 读取一路编码器，
最终分配仍应以 `EDCstm32.ioc` 的定时器规划为准。
