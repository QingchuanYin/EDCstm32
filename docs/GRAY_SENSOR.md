# 8 路纯模拟灰度传感器与寻迹

## 接线与电压

模块使用 74HC4051 将 8 路模拟灰度信号复用到一个 `OUT` 引脚。底板接线如下：

| 模块信号 | 底板网络 | MCU 引脚 | 固件功能 |
| :--- | :--- | :--- | :--- |
| `OUT` | `L3` | PA0 / ADC1_IN0 | 12 位模拟采样 |
| `EN` | `L2` | PA1 | 低电平使能 74HC4051 |
| `AD2` | `L1` | PB5 | 通道地址 bit 2 |
| `AD1` | `M` | PA4 | 通道地址 bit 1 |
| `AD0` | `R1` | PB4 | 通道地址 bit 0 |
| `ERR` | `R2` | PA5 | 只采集和显示，不参与控制 |
| 未连接 | `R3` | PA6 | 模拟模式，降低浮空输入功耗 |

> [!CAUTION]
> 模块可以使用 5 V 供电不代表 `OUT` 一定是 3.3 V 信号。首次连接前必须断开 PA0，
> 用万用表或示波器测量所有通道在黑、白表面上的 `OUT` 电压，并检查 `ERR` 的高电平。
> 只有这些信号的最大值不超过 3.3 V 才能直连 MCU；否则必须增加分压、缓冲或钳位
> 电路。模块、STM32 与 TB6612 必须共地。

`EN=0` 时的选通关系为：

| AD2 | AD1 | AD0 | 通道 |
| :---: | :---: | :---: | :---: |
| 0 | 0 | 0 | CH1（车体左侧） |
| 0 | 0 | 1 | CH2 |
| 0 | 1 | 0 | CH3 |
| 0 | 1 | 1 | CH4 |
| 1 | 0 | 0 | CH5 |
| 1 | 0 | 1 | CH6 |
| 1 | 1 | 0 | CH7 |
| 1 | 1 | 1 | CH8（车体右侧） |

## 标定和运行

1. 上电后车辆保持停车，OLED 显示 `WHITE`。让全部探头对准纯白背景，按 KEY1；
   固件平均采集 32 组白底数据。
2. OLED 显示 `SWEEP`。再次按 KEY1 后开始 5 秒倒计时，在此期间横向移动传感器，
   让黑线依次经过 CH1 到 CH8。
3. 显示 `READY` 表示标定成功，按 KEY2 开始寻迹，再按 KEY2 停止。`Line:YES/NO`
   单独表示当前是否检测到黑线；`READY` 只表示车辆已标定并停车待命。
4. 显示 `FAIL` 时，`Bad CH mask` 是失败通道位图：bit0 对应 CH1，bit7 对应
   CH8。检查黑线是否扫过对应探头、安装高度和模拟跨度，然后按 KEY1 重新标定。

标定逐通道记录相对白底偏移最大的黑线端点，因此兼容“黑色电压更高”和“黑色电压
更低”的模块，不需要在代码中猜测模拟极性。标定值保存在 RAM，重新上电后必须再次
标定。

## 控制与调试

- 控制周期为 10 ms，基础 PWM 和最终输出上限均为 5%。CH1 到 CH8 使用从 `-3.5` 到 `+3.5`
  的权重计算黑线位置。
- 有效黑线必须同时满足总强度、单路峰值和通道间对比度门限。弱小的全通道环境漂移、
  白底噪声以及整排探头同时落在同一灰度表面时均判为 `Line:NO`。
- OLED 中 `C` 为八路总强度，`P` 为最高单路强度，`D` 为最高与最低通道的对比度。
- 默认离散 PD 参数位于 `line_follower.h`：`Kp=20`、`Kd=60`，修正量限制为
  5 个占空比百分点。转弯时降低内侧轮占空比，外侧轮不会超过 5%。
- 丢线后保持最后一次转向最多 100 ms；仍未找到黑线时 PWM 清零。重新检测到黑线
  会自动恢复，KEY2 在任何运行状态下都能停止。
- `ERR` 的含义和有效电平尚无可靠资料，当前只显示原始电平。确认模块说明书和实测
  行为前不要将它用于急停或丢线判断。

首次上板应架空车轮，依次确认 CH1/CH8 的左右方向、电机 A/B 的左右轮映射以及修正
方向。之后先调整基础占空比，再调整 `Kp`，最后增加少量 `Kd` 抑制摆动。
